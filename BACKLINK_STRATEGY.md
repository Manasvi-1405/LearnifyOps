## Establish an authoritative baseline before execution

With the owner's existing access, export Search Console **Links → External links → Top linking sites**, **Top linked pages**, and sample/latest links. Export the currently accessible Seobility backlink detail, including source URL, target, first/last seen and link attributes. Use Ahrefs or Semrush only if already available; no new subscription is required or assumed.

Deduplicate by referring registrable domain and retain individual source pages. For each source, confirm HTTP status, the actual link, anchor, `rel`, destination, redirects, topical relevance and whether the source is company-owned, paid, user-generated or independent editorial. Distinguish links in database samples from links confirmed in live HTML. Preserve the export date and database scope. Do not label a nofollow link “bad”; record its referral/brand value separately.

Lost links can only be assessed when a historical export or existing account supplies previous observations. Then check whether the source was deleted, the anchor removed, or the destination became a 404. Request factual corrections only after confirming the original relationship and original URL. No lost/broken-link count can be supplied from the current evidence.

## Competitor evidence and limits

The [EDBAC University of Reading/Henley profile](https://edbac.org/program-comparison/1006) publicly describes that DBA programme and points readers to henley.ac.uk. This is a concrete example of a topically relevant institutional reference used by a competing programme. The [Council's school comparison directory](https://www.edbac.org/program-comparison/schools) is specifically for Executive DBA member schools.

LearnifyOps is an adviser in the supplied content, not demonstrated to be a degree-awarding member school. Do not imitate a university listing or claim membership. The useful lesson is to earn references appropriate to the business's actual role, contribute legitimate scholarship and verify any institution relationship. This is **public competitor-reference research**, not an Ahrefs/Semrush backlink-gap analysis. Full competitor backlink profiles and ranking/traffic advantages were not measured.

Do not pursue archived journals simply because an old page still displays a submission form. The current Kennesaw directory identifies some executive-education journals as archived; that makes them unsuitable as assumed active acquisition targets.

## Resource concepts for a legitimate editorial pitch

These are proposals only; none was added to the website or described as completed research:

1. A sourced DBA admissions due-diligence checklist: awarding body, entry review, research supervision, dissertation requirements, delivery and institution-specific information. A qualified reviewer must check every claim. Existing `/admissions` is the interim destination.
2. A practical framework showing how a real executive problem becomes a research question, with an independently reviewed example and references. Existing `/curriculum` provides context, but an original resource should exist before anyone asks editors to cite it.
3. An original, anonymised study of candidate questions or research-readiness barriers, only if lawful/consented data and a defensible method exist. Publish sample size, collection period, limitations and conflicts. Do not use identifiable lead data, manufacture results or generalise beyond the sample.

New pages, visible copy, research collection and publication require a separate review; the present task changes no visible wording.
